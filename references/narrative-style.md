# 叙事方式与文风规范

## 1. 决策主线（Decision Spine）

每篇案例只服务一个决策主线：**主角 → 情境 → 压力 → 备选方案 → 证据 → 决策点**。

- 主角必须是能拍板的人。若素材中的关键决策超出主角职权，二选一：把决策点重构到主角职权内的选择上（保留故事线），或更换主角。禁止让主角沦为执行者/见证者。
- 编年史只做减法：只保留能解释"这个决策为什么难"的里程碑。
- 至少两个备选方案都站得住脚，学生需要证据+假设+理论才能论证。

## 2. 开场钩子

第一段就是现场：具体时间（"2026年7月的一个深夜"）、具体地点、主角、摆在桌面上的数字或信件。300 字内回答：谁在决策？何时何地？桌上摆着什么？为何紧迫？随后用一句悬念过渡（"故事要从更早说起。"）进入回溯。**禁止行业综述式开头。**

## 3. 决策点的写法

- 回到"当时信息不全"的进行时：呈现各备选项的诱惑与恐惧，结果留到后文才揭示。
- 决策点可以显式标注（如【决策点一~五】），也可以用节奏显形（"他没有说的是，那天晚上他自己也没睡好。"）。
- 用直接引语制造张力：对话、邮件、备忘录、会议爆发（"安静了大概十秒钟，各种声音同时爆发"）。引语必须服务于决策压力，不是装饰。

## 4. 量化纪律

- 量化一切可量化的，但绝不编造数字。
- 每个关键数字给参照系：倍数（"差价四十倍"）、变化（"从4.2小时升至11.6小时"）、后果（"相当于每年烧掉一支三十人团队"）。
- 真实案例：数字带来源注；查不到的改定性或"约/估算"并注明。化名案例：全篇声明数据为教学演绎。

## 5. 结尾

- 停在决策时刻或开放追问，把判断留给课堂。
- 可保留一个画面感的收束动作（关灯、回消息、约酒），但不得给出"五条启示/三个成功密码"式结论，不得泄露真实结局（结局如需交代，只放教学笔记）。
- 文末接"（案例正文完，全文X字）"。

## 6. 文风细则

- 过去时态为主，第三人称；技术细节必须翻译成商业后果（Token 消耗 → 不可预测的变动成本）。
- 对话/引语段落用楷体，与叙述段落（宋体）形成视觉区分。
- 小节标题优先用当事人原话（「"我没有给员工做培训"」），其次冲突短语。
- 全中文引号“”‘’；嵌套引用外双内单；英文文献标题保留英文标点。
- 删尽宣传式形容词与全知判断（"值得被看见、被支持、被投资"式句子一律删除）。
