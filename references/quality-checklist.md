# 三层核验清单（交付前强制执行）

## 第一层：机器核验（脚本重开 docx 逐项断言）

**案例正文**
- [ ] 字数 8,000–10,000（Word 口径）
- [ ] 摘要 200–300 字；关键词 3–5 个
- [ ] 全文无"讨论题""启发思考题""适用课程"
- [ ] 文末有"（案例正文完，全文X字）"
- [ ] 直双引号/直单引号 = 0（英文文献原标题除外）
- [ ] 无元文本（"字数：约""教学笔记字数"等）
- [ ] 免责声明在（真实案例含资料来源；化名案例含"全部数据为教学演绎"声明）
- [ ] 图片有"图N"加粗图注；docx 可正常打开解析

**教学笔记**
- [ ] 字数 10,000–14,000
- [ ] 九节齐全、顺序正确、节名未改
- [ ] 思考题恰好 5 道
- [ ] 每题答案含【理论依据】与【案例分析】
- [ ] 含映射表与板书计划（含分钟数）
- [ ] 关键知识点+关键能力点（4 条）齐全
- [ ] 参考文献编号连续、真实可查
- [ ] 直引号 = 0；无元文本

## 第二层：人工研判（机器判不了，逐篇抽读）

- [ ] 开场 300 字内出现主角、场景、待决问题（不是行业综述）
- [ ] 每个决策点都是"当时信息不全"的进行时抉择
- [ ] 结尾开放：没有结论式命题、没有泄露真实结局
- [ ] 答案四段式：理论→案例应用→比较→课堂结论，且结论可辩护、承认假设
- [ ] 5 道题确呈"诊断→分析→评价→决策→延伸"递进
- [ ] 无颂扬语调、无全知判断

## 第三层：协作核验（案例↔笔记对照）

- [ ] 每道题在案例正文中有对应情节与数据锚点
- [ ] 答案中引用的数字与案例正文逐字一致
- [ ] 笔记未把案例中标注为演绎/未核实的数据当作既定事实
- [ ] 案例正文未泄露笔记中的分析结论与真实结局
- [ ] 案例标题在两份文档中逐字一致

## 转换后专项复核（本项目血泪教训）

任何批量格式转换（改结构、换引号、改标题层级、合并/移动节）之后：
- [ ] 主标题未被降级为编号节
- [ ] 小标题未被部分替换污染（整行替换，不能只换前缀）
- [ ] 散文段落该枚举化的已枚举化（或按家格式保留散文，如教学目标）
- [ ] 节内交叉引用（"见第X节"）与新编号一致
- [ ] 引号方向正确（开“闭”、跨段引语、嵌套单引号逐处抽验）
