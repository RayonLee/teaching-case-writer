# 教学笔记：结构与文档格式规范

本规范以审定参考稿《参考教学笔记_从50人到2人_AI编程成本豪赌.docx》为最终标准。

## 1. 固定节序（九节，节名不编号、不增删、不改名）

| # | 节名 | 内容与要求 |
|---|---|---|
| 0 | 标题页 | "教学笔记"（幼圆16pt 左对齐）+ 案例标题（幼圆16pt 加粗居中，与案例正文标题逐字一致） |
| 1 | 摘要 | 2–3 段：故事梗概（可含结局，笔记不受"不泄结局"约束）→ 问题链 → 教学问题定位（"本案例的核心不在于……而在于……"）；不含关键词 |
| 2 | 教学目标 | **一段散文**（非枚举）：以"培养学生掌握……；训练其运用……"句式，覆盖案例全部理论训练点与能力点 |
| 3 | 教学对象 | 两段：适用课程（《》列出，含在何章节如何使用）＋适用对象（MBA/EMBA/本科高年级/高管培训等） |
| 4 | 启发思考题 | 恰好 5 道，每题独立成段、**不加序号**；按"诊断→分析→评价→决策→延伸"递进；题干聚焦概念冲突（如"这类新型成本与传统人力成本有何本质差异？"），不复述情节细节 |
| 5 | 板书计划 | 先一句话定位（"建议按照以下课堂计划展开授课，案例分析建议在90分钟内完成"），再按时间块展开，每块标题加粗："前期准备以及案例阅读（10分钟）→ 通过课堂互动聚焦案例问题（30分钟）→ 小组陈述问题答案（30分钟）→ 案例总结与反思（20分钟）"。基准节奏 10+30+30+20，可按案例定制，但每块须写清教师与学生活动 |
| 6 | 思考题分析 | 每题依次为：加粗段"思考题N：<题干逐字>"→"【理论依据】理论名[文献编号]"→理论展开（提出者、核心主张）→结合案例（引用案例数字与情节）→加粗独立行"【案例分析】"→一段可辩护的课堂结论（承认假设与权衡，不假装唯一答案） |
| 7 | 背景信息 | 行业/政策背景（引用真实政策文件并列参考文献）＋本案例特点概括，供不熟悉行业的教师备课 |
| 8 | 关键要点 | 两个加粗小节："关键知识点"（以"第一，……第二，……"覆盖全部教学点，每点一句判断句）＋"关键能力点"（4 条枚举：理论运用、数据测算与决策、分析综合、批判性思维） |
| 9 | 参考文献 | [1]…[N] 编号，GB/T 7714 格式，外文文献保留英文原名与标点，附 DOI/URL |

## 2. 必备表格

| 表 | 位置 | 结构 |
|---|---|---|
| 映射表 | 启发思考题后或思考题分析开头 | 案例问题 × 理论知识点 × 案例情节（5 行，每题一行），用于教师一眼看到"题—理论—情节"对齐 |
| 每题关键要点表（可选但参考稿有） | 各题思考题分析内 | 关键要点 × 分析说明（3–4 行），把该题答案压缩为课堂可板书要点 |

表格用 Table Grid 样式，表头加粗，单元格文字 10.5pt（五号）。

## 3. 文档格式

与案例正文同一体系：A4、上下 2.54cm、左右 2.8cm、无页眉页脚；正文 Times New Roman+宋体 12pt、1.5 倍行距、首行缩进 2 字符、两端对齐；节标题用真实 Word Heading 2 样式（宋体 14pt 加粗）。字数 10,000–14,000。

## 4. 语气

分析性、理论驱动、直接给答案与计算；**不再讲故事**——案例中的情节在笔记中只作为分析证据被引用（"北京团队的应对方式，与作业成本法的逻辑高度一致"），不复述叙事。
